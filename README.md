# Creative Idea Generator

A beginner-friendly Google Colab notebook that asks an OpenAI model for creative, practical uses for everyday objects.

## Run in Google Colab

Open `creative_ideas.ipynb` in Colab. Run the install cell, then the generator cell. Enter your OpenAI API key only at the secure runtime prompt; never add it to this repository.
